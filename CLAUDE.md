# CLAUDE.md - Fake Review Detection with Autoencoders and Deep Learning

7th-semester B.Tech CSE (AI & ML) major project. Evaluated by report + live demo + viva, so the
student must be able to explain every line. **Clear code over clever code.**

## Goal
Two autoencoder-based detectors compared against standard baselines, plus a proposed hybrid:
1. **Anomaly detection (no labels):** AE trained only on genuine reviews; high reconstruction error = fake.
   Model A (dense AE on SBERT), Model B (LSTM seq2seq AE on GloVe), Model C (denoising AE, VAE).
2. **Hybrid (contribution):** Model D = AE latent z + reconstruction error + style (+ Yelp behaviour) → MLP / XGBoost,
   frozen vs. joint fine-tuning, feature groups switchable for the ablation.

## Hard rules
- **Honesty:** never invent, estimate or hard-code results. Every number in tables/plots/report must come from a
  run logged in `results/runs.csv`. Not run yet → write `TBD`. Tables are generated by `src/evaluate.py`.
- **No leakage:** vectorisers, vocabularies and scalers are fit on the TRAIN split only. Anomaly detectors train on
  genuine TRAIN rows only; the threshold is chosen on VAL and frozen for test. Never oversample val/test.
- **Fixed splits:** 70/15/15 stratified with `split_seed` (never changes); saved as review-id lists in
  `data/processed/<dataset>/splits.json`. `seed` (42, 43, 44) only changes model randomness.
- **Yelp is optional:** every Yelp-dependent step must skip cleanly when `data/raw/yelpchi/` is missing.
- **Budget ₹0:** no paid APIs. **Compute:** CPU smoke tests (`--sample 500`) locally; full runs fit one T4.
- **Stack:** Python 3.10+, PyTorch (not TF), scikit-learn, transformers, sentence-transformers, NLTK, UMAP,
  SHAP/LIME, Optuna, Streamlit, XGBoost. Ask before adding other dependencies or large downloads.
- Citations: never fabricate details; mark unsure ones `[verify]`.
- Git: commit at the end of each phase (`phase-N: ...`). Author identity: `plmcodes <224992936+plmcodes@users.noreply.github.com>`.

## Layout
- `configs/default.yaml` shared settings; `configs/models/<model>.yaml` one per model; `configs/models/tuned/` Optuna output.
- `src/data_loading.py` (common schema) → `src/preprocess.py` (text views + splits) → `src/features.py` (`DataBundle`, cached features)
- `src/models/*.py`: every model is a `Runner` with `fit / score / save / load` (`src/models/base.py`). Score: higher = more fake.
- `src/train.py` one model, one command; `src/evaluate.py` metrics, tables (from runs.csv) and plots; `src/tune.py` Optuna;
  `src/explain.py` SHAP + LIME; `src/modern_fakes.py` Phase 8; `src/diagram.py` architecture figure; `app/streamlit_app.py` demo.
- `results/runs.csv` one row per (run, eval set). `results/predictions/` per-review scores (git-ignored, regenerable).
- `checkpoints/<run_id>/` with `meta.json` (full config + frozen threshold). Git-ignored; on Colab it lives on Drive.

## Conventions
- Docstrings explain *why*; short comments; no clever one-liners.
- New model = new YAML in `configs/models/` + a Runner registered in `src/models/__init__.py`.
- Ablations/variants use `--tag <name> --set key=value` so they get their own run_id and table row.
- Laptop CPU is slow for transformers: DistilBERT locally only via `distilbert_cpu` (2k-train subset, reported as its own row).
