# Data

Raw data is **never committed or redistributed** (`data/raw/` and `data/processed/` are git-ignored).
Every file comes from its original public source, or from the authors on request.

## Quick start

```bash
python -m src.download_data --glove     # Salminen + Ott + GloVe 6B 100d
```

## Where each file goes

| Dataset | Put it here | Source | Licence / access |
|---|---|---|---|
| **Fake Reviews Dataset** (Salminen et al., 2022) - main train/test set | `data/raw/salminen/fake reviews dataset.csv` | OSF project https://osf.io/tyue9/ (also on Kaggle as "Fake Reviews Dataset") | public |
| **Deceptive Opinion Spam Corpus v1.4** (Ott et al., 2011/2013) - cross-domain test set | `data/raw/ott/op_spam_v1.4/...` (unzipped) | https://myleott.com/op_spam_v1.4.zip | CC BY-NC-SA 3.0 (see its LICENSE file) |
| **GloVe 6B 100d** (Pennington et al., 2014) | `data/raw/glove/glove.6B.100d.txt` | https://nlp.stanford.edu/projects/glove/ (mirror: huggingface.co/stanfordnlp/glove) | PDDL |
| **YelpChi** (Rayana & Akoglu, KDD 2015) - *optional* | `data/raw/yelpchi/metadata` and `data/raw/yelpchi/reviewContent` | email the authors | research use, on request |
| YelpNYC / YelpZip - *optional* | not wired in yet (same format as YelpChi) | email the authors | research use, on request |
| Modern AI fakes (Phase 8) - *ours* | `data/raw/modern_fakes.csv` | generated by `python -m src.modern_fakes generate`, or written by hand | ours (committed) |

## Verified file formats

**Salminen** - checked on the downloaded file (40,432 rows, SHA-256 `ea034229...e1e1a`):

| column | values |
|---|---|
| `category` | 10 Amazon categories, e.g. `Home_and_Kitchen_5` (the `_5` suffix = Amazon 5-core subset; we strip it) |
| `rating` | 1.0-5.0 |
| `label` | `CG` = computer-generated (GPT-2) → **1 (fake)**, `OR` = original human review → **0 (genuine)** |
| `text_` | review text |

**Ott** - 1,600 `.txt` files: `{positive,negative}_polarity/{deceptive_from_MTurk,truthful_from_TripAdvisor|truthful_from_Web}/fold1..5/`.
`deceptive` → 1 (fake), `truthful` → 0. 800/800 split. No star ratings.

**YelpChi** - not received yet. `src/data_loading.py::load_yelpchi` expects the authors' tab-separated
`metadata` (user_id, prod_id, rating, label, date) and `reviewContent` (user_id, prod_id, date, text) files,
with label -1 = filtered (fake). **[verify]** this against the real files when they arrive. Until then every
Yelp step is skipped automatically: the pipeline runs end to end without it.

## Caveats (for the Limitations chapter)

- **Yelp labels** come from Yelp's own filter: close to ground truth, but not certain.
- **Salminen fakes are GPT-2 generated**, not written by modern LLMs or paid human spammers. Phase 8
  tests whether the detectors still work on fakes from a recent open-weights model.
- A RANLP 2023 paper reports quality problems (noise) in the Amazon review data behind the Salminen
  dataset **[verify exact citation]**.
- **Ott** fakes were written by Mechanical Turk workers about 20 Chicago hotels. That is a different
  domain (hotels vs. products) and a different kind of fake (human vs. GPT-2), so cross-domain scores are
  expected to drop.

## Processed cache (`data/processed/`)

Created automatically on first use: `<dataset>[_s<sample>]/clean.pkl` (cleaned text views),
`splits.json` (fixed 70/15/15 review-id lists), `sbert_all-MiniLM-L6-v2.npz`, `style.pkl`, and
`glove/` (GloVe as .npy for fast loading). Delete the folder to rebuild everything from raw data.
